# Hybrid ranking and source-backed wiki statements

The scoped hybrid engine previously used `1 / (60 + rank)` with a zero-based
rank. In a small collection, agreement among lower-ranked candidates received
almost twice the contribution of a leader found by only one modality. The
source change uses harmonic reciprocal ranks with equal modality weights and
retains one vote per eligible document, global semantic ordering, exact selected
passages, current authorization, deterministic ties and all existing bounds.
No expected document IDs, vocabulary, source names or query rewrites decide the
rank. This changes the ranking tradeoff; unchanged independent semantic
qualification must assess it before acceptance.

For source-backed wiki catalogs, the original draft guard required an immutable
source citation only in the lead. Section statements could carry only graph
status citations while advertising evidence entailment. The draft and final
receipt now require a source-span citation for every synthesized statement when
source evidence is available. Writer, repair and verifier instructions distinguish
internal freshness from evidence that a real-world fact changed. The independent
verifier remains necessary: arbitrary source citations do not establish support.
Existing governed graph-only catalogs remain supported. Compiler version 19 and
writer/verifier prompt versions 13/5 prevent reuse of the prior article contract.

Authored regression coverage includes symmetric lexical/semantic leaders, weak
tail agreement, existing duplicate/partition/chunk-count controls, and actual
source publication/index/search in both backends and two named spaces using
explicitly controlled transport vectors. Wiki controls reject a graph-only
section beneath a sourced lead, preserve verifier rejection after a span is
present, reject a clean-looking receipt lacking per-statement source evidence,
and retain graph-only catalog behavior. Controlled vectors and test sources are
not provider relevance acceptance. No frozen known-answer corpus, expected
passage, quality threshold, provider cap, retry limit or original run is changed.
