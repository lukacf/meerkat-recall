This separates the original static hash dependencies. A literal digest in the
command creates a cycle: command -> orchestration manifest -> input bundles ->
runtime review -> command digest. With the descriptor path, materialization is
ordered: fixed command paths, runtime review, input bundles, orchestration
manifest, descriptor, complete gateway input inventory, launch configuration,
gateway manifest, then independent outer run approval. The descriptor belongs
to that complete inventory and outer review. Its content hash must not be added
to the nested runtime review, which would recreate the cycle. No file grants
execution, spending, installed qualification or runtime acceptance on its own.

The descriptor is read through the existing bounded original-inode reader and
the manifest still passes the same exact digest validation. G continues to
stage and hash the complete private input tree and mount it read-only; the
independent runtime predicate still binds the original launch, inventory and
command before any provider cohort is opened. Offline controls reconstruct both
profile input chains with actual file readers and gateway inventory checks.
Their inert installed evidence and unapproved review are input-custody fixtures,
never provider relevance or product acceptance.
