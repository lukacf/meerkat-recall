D freezes `container-boundary-contract.json` for F's new container extension.
The ten error cases use the active shared ErrorCode contract; six coverage cases
use the actual scoped search DTO. Coverage missing/pending/stale/retracted/erased
is a successful but partial search response, distinct from an HTTP or MCP error.
A complete zero-result control first requires a positive exact-revision public hit.
MCP transport authentication refusal is distinct from a tool-level typed error.

Oversized output must come from complete evidence of actually published
supported Graph claims exceeding the 262144-byte encoded search DTO limit. A reduced
collector cap, arbitrary oversized raw response or Metadata-only pending fixture
cannot qualify it. Missing actual preparation remains unmet. Independent restore
clients capture original monotonic intervals, readiness and A/B data reads; erasedA
must never reappear, and final404 alone cannot prove the replay barrier interval.
No production fault switch or internal-state injection is authorized.

claims; their quoted JSON bytes alone exceed the existing response limit. One
explicitly new limit-10 request keeps the same query and revision constraints.

MCP capture bounds. The precise pinned arithmetic includes all three additive
rendered-reference fields, the actual `ToolResponse {ok:true,data:...}` envelope,
RMCP's JSON-string encoding, finite score allowance and stream framing reserve.

unmet: the installed extraction planner has a 12000-byte window. Root explicitly
approved this equivalent selected-response gate at 02:30 and 02:36 on October 7.

or other gate was reduced. Literal arithmetic does not prove actual publication,
selection, transport behavior, live quality or consumer fallback execution.

is separately qualified through supported quiesced exports and bounded typed

and byte-canary searches alone cannot establish complete physical closure.
